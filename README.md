# Pixel Pomodoro Study Club

싸이월드 미니홈피 감성의 3인용 실시간 캠스터디 웹사이트를 만들어줘.
전체적인 디자인은 아기자기한 레트로 픽셀/도트 감성의 파스텔 톤으로 해줘.
화면 중앙에는 미니룸(방 꾸미기 공간)이 있고, 방 안의 액자나 모니터 프레임 3개 안에 접속한 친구들(최대 3명)의 실시간 웹캠 화면이 나오게 해줘. (WebRTC 또는 PeerJS를 활용해서 별도 유료 서버 없이 3명이 연결되게 해줘)
화면 한쪽에는 3명이 함께 시간을 맞출 수 있는 '뽀모도로 타이머(25분 공부, 5분 휴식)'를 넣어주고, 하단에는 서로 응원 메시지를 남길 수 있는 간단한 '방명록'과 유튜브 링크를 넣으면 노래가 나오는 'BGM 플레이어'를 만들어줘.
